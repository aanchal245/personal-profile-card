
# 🌟 Personal Profile Card

A responsive and interactive Personal Profile Card built using React.js. This project allows users to view and edit their profile information, manage skills, and interact with different features while learning the fundamentals of React.

## 📸 Features

- **Personal Profile:** Displays name, job title, email, phone number, location, and GitHub profile.
- **Edit Profile:** Update your name dynamically.
- **Manage Skills:** Add new skills and delete existing ones.
- **Like Counter:** Interactive Like button with a live counter.
- **Availability Toggle:** Change your availability status dynamically.
- **Focus Input:** Automatically focus on the skill input using React's useRef Hook.
- **Local Storage:** Saves the updated name and skills in the browser so they remain available after refreshing the page.
- **Greeting Message:** Interactive button that displays a welcome message.
- **Responsive Design:** Styled to work across desktop and mobile screens.

## 🛠️ Tech Stack

- **React.js** – Building reusable UI components.
- **JavaScript (ES6+)** – Application logic and interactivity.
- **HTML5** – Application structure.
- **CSS3** – Styling and responsive design.
- **Vite** – Development server and build tool.
- **Browser Local Storage** – Persisting profile data.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd personal-profile-card
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Open the local URL provided by Vite in your terminal, usually:

```text
http://localhost:5173
```
